ℹ Grid Parameter Guide
MIN SPACING 1500
Minimum gap between grid levels. Prevents overtrading in low volatility. Acts as a floor — spacing never goes below this.
MAX SPACING 5000
Maximum gap between grid levels. Caps grid width during extreme volatility so orders aren’t too far apart.
ATR DIVISOR 2.0
Sensitivity control. Lower = wider spacing for same ATR. Formula: spacing = max(MIN, min(MAX, ATR / DIVISOR))
TP MULTIPLIER 1.0
Take-profit as a ratio of spacing. 1.0 means TP = spacing. Higher values increase win size per trade at the cost of fewer hits.
BASE LOT 0.01
Position size per grid level. At 0.01, each pip move = $0.10. A 1500-pip win = ~$15 per position.
All values update in real-time via SSE from the running simulation. Config constants are in broker.py.
